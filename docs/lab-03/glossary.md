# Lab 3 Domain Glossary

| Term | Meaning |
|---|---|
| User | Authenticated account with exactly one role and active/inactive state. |
| Requester | Role that submits and accesses its own tickets and permitted attachments. |
| Ticket Requester | User who submitted the ticket; distinct from operational owner. |
| Ticket Owner | Zero or one active eligible IT Staff/Administrator assigned operational responsibility. |
| Requested Priority | Requester's submitted priority; retained separately from staff prioritization. |
| IT Priority | Operational priority initially copied from Requested Priority. |
| Public Comment | Append-only communication visible to authorized ticket participants, not anonymous internet users. |
| Internal Note | Append-only operational communication hidden from Requesters. |
| Resolution indication | Requester statement that the problem appears resolved; not formal Resolved/Closed status. |
| Initial password | Local-lab credential requiring replacement before normal application access. |
| Engineering contract | Approved specification, API/UI contracts and traceable test plan governing implementation. |
